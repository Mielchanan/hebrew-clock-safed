# elementor-premium-design

סקיל ל-Claude לבניית אתרי Elementor ו-WordPress, בעברית (RTL) ובאנגלית, שנראים פרימיום ולא כמו "אתר AI".
מבוסס על שלושה סקילים בקוד פתוח, ומותאם ל-Elementor, לעברית ול-GSAP + Lenis.

## התקנה
- **Claude (אפליקציה):** Settings > Capabilities > Skills > Upload, ולהעלות את התיקייה כקובץ ZIP.
- **Claude Code:** להעתיק את התיקייה אל `~/.claude/skills/elementor-premium-design/`.
